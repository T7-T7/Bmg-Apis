# BMG APIs

API platform interface and builder — Next.js App Router + Node.js runtime.

## Development
- Node.js 20.9+
- `npm install`
- `npm run dev`

## Routes
- `/` Dashboard
- `/apis` API catalog
- `/apis/[slug]` API detail/documentation
- `/create` API Builder
- `/my-apis` Manage APIs
- `/docs` Platform documentation
- `/status` Service status

This repository currently begins with the frontend foundation. API creation, storage, publishing, and live monitoring will be connected in later stages.
